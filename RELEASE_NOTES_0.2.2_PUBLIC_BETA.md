# LinuxFIX Public Beta 0.2.2

LinuxFIX Public Beta 0.2.2 is now available for Android.

## Highlights

- Troubleshooting workspaces for Arch Linux and Debian.
- AI-assisted analysis for terminal errors, logs, and Linux how-to questions.
- Polish and English interface support. AI replies follow the selected language.
- Account-based analysis history with automatic retention controls.
- Four interface color themes, light and dark modes, and system, terminal, and elegant fonts.
- Refined Hyprland-inspired distribution tiles with shatter effects, loading sequences, sound, and haptic feedback.
- Live typewriter-style AI answers with automatic scrolling and synchronized haptics.
- Improved input validation, authentication, session handling, request rate limiting, API responses, and security headers.
- Privacy Policy, Terms of Service, Refund Policy, and in-app privacy consent.

## Installation

1. Download the Android APK from the Assets section below.
2. Allow installation from this source if Android requests permission.
3. Install the APK and launch LinuxFIX.

## Important notes

- This is a public beta. Features and service availability may change during development.
- AI analysis requires the LinuxFIX backend and its configured HTTPS endpoint to be online.
- LinuxFIX never executes suggested commands automatically.
- Review every command before running it, especially commands involving `sudo`, disks, partitions, bootloaders, file systems, or permissions.
- Never paste passwords, API keys, access tokens, private keys, or other secrets into the application.
